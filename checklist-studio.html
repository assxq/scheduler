    스케줄러와 같은 프로젝트를 쓰므로 URL·키는 자동으로 채워집니다. 최초 1회만 Supabase 대시보드 → SQL Editor에 아래를 붙여넣고 실행하세요. 스케줄러 테이블은 건드리지 않고 체크리스트용 테이블만 새로 만듭니다. 여러 번 실행해도 에러가 나지 않습니다. 
    create table if not exists checklist_state (
  id int primary key,
  data jsonb,
  updated_at timestamptz default now()
);
alter table checklist_state enable row level security;
drop policy if exists "chk anon all" on checklist_state;
create policy "chk anon all" on checklist_state
  for all using (true) with check (true);
do $$ begin
  alter publication supabase_realtime add table checklist_state;
exception when duplicate_object then null; end $$;
    ⚠ anon key로 누구나 읽고 쓸 수 있는 개인용 설정입니다. 링크와 키를 외부에 공유하지 마세요.
